# 《我如何看世界》：爱因斯坦原文中译与晚年思想校勘

这不是一篇经过润色的“爱因斯坦孤独自述”，也不是把几十年间的言论拼成一篇他从未写过的文章。

这个项目做三件事：

1. 依据 1934 年德文初版影印件，给出 *Wie ich die Welt sehe* 的完整中文翻译；
2. 对照 1930 年首次发表的英文文本，说明版本差异和容易误译的词；
3. 把 1932—1955 年间与原文相关的后续表达单独列出，辨明哪些是延续、补充或真正的立场修正。

## 最重要的校正

网络上常见的概括“我的身心从未属于别人”不是爱因斯坦原句，也会把原意推得过远。

原文说的是：他从未“全心全意地归属于”国家、故乡、朋友圈，甚至最亲近的家庭；面对这些联系，他始终有不曾消退的疏离感和对独处的需要。他谈的是**归属的限度**，不是否认关爱、责任或一切人际联系。1932 年他又明确说，对一个追求真、美与正义的“无形共同体”的归属感，使孤单感没有滋长起来。两句话合读，才接近他的完整意思。

## 底本判断

主文采用 1934 年阿姆斯特丹 Querido Verlag 版 *Mein Weltbild* 中的德文篇章 *Wie ich die Welt sehe*（书内第 11—17 页）。理由是它是目前可逐页核验的德文出版文本。1930 年英文首刊 *What I Believe* 用来校对语义和辨认版本差异。

1953 年 Europa Verlag 出版的是“经作者审阅并大幅扩充的新版”整部文集，其中仍收录本篇。这个事实可以说明爱因斯坦晚年仍允许它代表自己，却**不能自动证明本篇每一句都在 1953 年重新改写过**。因此，本项目不把 1953 年的文集说明夸大成一个并无证据的“最终修订稿”。

## 编辑原则

- 正文只翻译一个可核验的历史文本，不把后来的材料插回原文。
- 译文首先追求意思、语气和逻辑关系准确，其次才是中文的修辞效果。
- 不把“独处”改写成痛苦的“孤独”，也不把“疏离感”淡化成普通的距离感。
- 原文中的时代性判断照实保留，并在注释中交代约 1930 年的历史语境。
- 没有可靠出处的名言，不因其“像爱因斯坦会说的话”而收入。
- 项目不做形式化双语排版；德语只在确有校勘必要时以短词或短语出现。
