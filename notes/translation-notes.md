# 关键翻译说明

本页不做全文双语对照，只保留会实质影响中文理解的短词和短语。表中的“1930 英文”是首次发表文本中的对应表达；它是版本见证，不被假定为逐字等同于 1934 年德文。

| 位置 | 关键词 | 本译处理 | 理由 |
|---|---|---|---|
| 开头 | *Erdenkinder* | 尘世之子 | 字面可作“地球之子”。“尘世”保留人类短暂停留的语气，但不增加宗教教义。 |
| 互惠 | *Genügsamkeit* | 节制知足 | 同时包含少取、简朴和以已有为足。只译“节俭”会过窄，只译“知足”又会削弱劳动伦理。 |
| 自由意志 | *innere Notwendigkeit* | 内在必然性 | 与“外在强制”相对，指人的意欲也有因果条件；不是“听从内心”。 |
| 叔本华句 | *nicht wollen, was er will* | 不能决定自己想要什么 | 德文利用两个“意欲”的反身悖论。中文正文优先让意思可懂，而不机械复制句法。 |
| 人生目的 | *Selbstzweck* | 目的本身 | 爱因斯坦否定的是把安逸和幸福当作终极自足目的，不是否定一切舒适或幸福。 |
| 价值顺序 | *Güte, Schönheit und Wahrheit* | 善、美与真 | 保留原文次序，不按中文习惯改成“真、善、美”。 |
| 独行 | *Einspänner* | 惯于独行的人 | 本义涉及单马挽具或单驾马车，作人时指不合群、独来独往者。译成“孤独的人”会预先加入痛苦情绪；“独驾者”又不够自然。1930 英文用了“只适合单套挽具的马”的明喻。 |
| 归属 | *nie mit ganzem Herzen angehört* | 从未全心全意地归属于 | “全心全意地”是不可删的程度限定；“归属”也不是“身心所有权”。 |
| 疏离 | *Fremdheit* | 疏离 | 兼有陌生、异己之感，比普通“距离感”强；但不必然等于敌意。 |
| 独处 | *Bedürfnis nach Einsamkeit* | 对独处的需要 | 此处是主动需要。现代中文“孤独”常偏向痛苦、匮乏，容易同下一句“不为此遗憾”冲突。 |
| 共鸣 | *Konsonanz* | 共鸣 | 原义带有音乐中的和谐、协和，和“相互理解”并列。 |
| 民主 | *unpersönlicher Charakter des Wahlmodus* | 选举方式所带来的非人格化 | 1930 英文作“党派结盟的非人格性质”，1934 德文则明确落在选举方式；两版不可互换。 |
| 国家照顾 | *unser Staatsbetrieb* | 我们这里的国家制度 | 这是约 1930 年身处德国时的历史指称。若译成无时间标记的“我们的国家”，现代读者容易误认说话地点。 |
| 军事 | *Militär* | 军事制度 | 在列队、命令和战争的语境里，指军队及其制度性文化，不只是抽象的“军国主义”。 |
| 爱国叫嚣 | *Vaterländerei* | 爱国主义叫嚣 | 是带贬义的夸张爱国姿态，强于中性的“爱国”。 |
| 神秘 | *das Geheimnisvolle* | 神秘之物 | 指经验中不可穷尽、令人惊异的一面，不是某个秘密，也不是神秘主义学说。 |
| 宗教性 | *Religiosität* | 宗教性 | 指一种面对不可穿透之存在、理性与美的知与感；紧接着他排除了奖惩人的人格神。 |
| 理性 | *Vernunft* | 理性 | 原文把人的理性与自然中显现的理性相互映照。这里的词可以含秩序与可理解性，不宜直接人格化为一位“智慧者”。 |
| 存在万物 | *Bau des Seienden* | 存在万物之结构 | 比“宇宙结构”范围更抽象，指一切存在者或存在整体的构造。 |
| 生命永恒 | *Ewigkeit des Lebens* | 生命之永恒 | 上一句刚否定个体死后继续存在，因此不能解释成个人灵魂不朽。它指向生命或存在整体的持续奥秘。 |

## 三个特别容易造成思想误判的地方

### “不信自由意志”不等于“无须负责”

原文说，因果必然性的意识能缓和“容易使人瘫痪的责任重负”，并成为宽容的来源。它没有推出“行为没有后果”或“制度不应追责”。同一篇文章仍明确讨论社会义务、领导者责任和政治制度。

### “宗教性”不等于信奉人格神

爱因斯坦在同一段内先称自己“深具宗教感”，随后明确排除会奖惩造物、具有类人意志的上帝，也排除个人死后延续。译文必须同时保留这两面；只摘其中一面，就会把他改造成传统有神论者或把“宗教性”一词删空。

### “群体迟钝”不等于反民主

他把创造归于具体人格，同时把民主列为政治理想，要求个人受尊重、领导者可由被领导者选择。这里批评的是群体心理与偶像化，不是主张由不受制约的个人统治。

## 标点和语气

- 德文长句在中文中适度拆分，但因果、转折和限定关系不拆散。
- 原文中的激烈比喻，如“猪群的理想”“一根脊髓便足够”，照实保留，不替作者降调。
- 历史时间词在正文中译成“当时”，并由阅读提示说明原文的“今天”约指 1930 年。
- 为可读性采用现代汉语，不模拟民国译笔，也不把原文抬高成格言体。
